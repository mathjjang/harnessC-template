# AGENTS.md — 협업 저장소 규칙 (모든 에이전트 공통)

- 이 저장소는 두 조직이 같이 본다. 한쪽의 내부 문서·코드·원가·공수·내부 판단을 여기 쓰지 않는다. 다른 저장소의 경로나 기록 ID를 인용하지 않는다.
- 결정은 `decisions/DEC-<YYMMDD>-<slug>.md`에만. 회의록에는 결정의 링크만. 상태는 `proposed` → 양측 확인 → `agreed`. 되돌릴 땐 새 DEC + 옛 것 `superseded`.
- 회의록·결정은 한국어, 결론 먼저, 단정문. 이미 양측이 확인한 문서는 본문을 고치지 않고 개정 이력에 추가한다.
- `sources/`는 수정하지 않는다. 새 자료는 추가만 하고 `manifest.json`에 해시를 적는다.
